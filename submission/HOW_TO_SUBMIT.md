# How to submit Oriel (T3N Agent Build Challenge)

Listing: https://superteam.fun/earn/listing/t3n-agent-build-challenge  
Deadline: **16 September 2026, 15:59 UTC**  
Winners announced by: 23 September 2026  
This listing is **HUMAN_ONLY** — submit from your Superteam wallet account, not the agent API.

## Before you open the form

1. Claim a T3 identity and API key at https://go.terminal3.io/adk-community  
   Save the **DID shown on that page**. That is the eligibility DID.
2. Confirm the GitHub repo is public: https://github.com/Takumixbt/oriel
3. Create a Google Doc:
   - New Doc → paste everything from [`GOOGLE_DOC.md`](./GOOGLE_DOC.md)
   - Insert the PNGs from [`screenshots/`](./screenshots/) where marked
   - Share → **Anyone with the link → Viewer**
   - Copy the Doc URL
4. Optional bonus: post on X tagging [@terminal3io](https://x.com/terminal3io) with the repo or Doc link

## Earn form fields

Use [`EARN_FORM.md`](./EARN_FORM.md). Paste the Google Doc URL into **Link**.

## After submit

- Keep the Doc editable only by you; leave public view on
- If you later get funded certifier/target keys + a public HTTPS gateway, run the live scripts and append a redacted transcript to the Doc
- POC for credits/questions: https://t.me/wardumb (quote “Superteam” + your DID)
